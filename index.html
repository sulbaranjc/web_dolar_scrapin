¿Qué es esto?

Esta landing imita una casa de cambio con varios pares de divisas. El objetivo del ejercicio es que con Python hagas web scraping del valor USD→EUR mostrado arriba.

  • Contenido estático (sin backend).
  • Estructura semántica y selectores claros.
  • Muchos “distractores” reales: más pares, cards, y tabla.

Preguntas frecuentes

¿Los datos son reales?

No. Todas las cifras están simuladas y se incluyen solo para practicar scraping.

¿Dónde está el valor que debo extraer?

En el elemento con ID usd-eur-rate dentro del bloque “Valor destacado”.

¿Puedo cambiar el formato?

Sí, puedes modificar HTML/CSS/JS a tu gusto; el script de scraping debería adaptarse a selectores estables.
